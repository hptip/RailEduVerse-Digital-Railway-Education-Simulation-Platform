# Hình ảnh concept do AI tạo riêng cho UTTVR
- 00_Overview: phong cách chung, không thay cầu SO201 hay tàu theo hình.
- 01_OCL_Design: cột H, chi tiết lắp ghép, bốn biến thể.
- 02_Tunnel_Design: núi rừng, núi đá, cửa xiên, hai ray, nội thất, segment.
- 03_Subgrade_BIM_Viewer: ba kiểu nền, ô hình thoi, phân lớp, các chế độ xem.

Bỏ qua toàn bộ kích thước, tốc độ, điện áp, lý trình, thông số và tuyên bố về tiêu chuẩn xuất hiện trong ảnh. Chúng không phải dữ liệu kỹ thuật đã kiểm định. Hình ảnh UI chỉ minh họa chức năng, không thay layout/branding hiện tại. Nội dung Markdown và JSON ưu tiên hơn ảnh. Không đưa ảnh vào Assets hoặc runtime. Không dùng ảnh làm texture.
